# 使用说明

## 适合什么

这套工作流适合以设定驱动的类型小说、奇幻、科幻、历史架空、悬疑、玄幻、都市异能和长篇系列。它同样可以辅助人物驱动的小说，但必须承认：设定为故事提供冲突土壤，人物的选择决定作品最终的情感重量。

## 5 分钟启动

1. 复制 `templates/novel-project` 成为新小说目录。
2. 在 `01-创作意图.md` 写下你已经拥有的设定，不必完整。
3. 加载 `.github/skills/deep-novel-workflow/SKILL.md`。
4. 使用下面的开场语：

```text
加载 Deep Novel Workflow。请从阶段 1 开始。
我的设定种子如下：
<粘贴 01-创作意图.md 的内容>

先帮助我建立世界圣经。所有新增内容必须标为候选；在我明确确认前，禁止生成完整故事线，也禁止把候选写入 Canon。
```

5. 在每个 `需要作者决定` 节点作答。可以选择、混合、删改或要求重做。

## 推荐对话节奏

### 共建世界

```text
请只处理“资源与权力”这一层。给我 3 组互相冲突的候选，并分别说明：谁获益、谁受害、会产生什么日常生活细节，以及能导出什么个人困境。不要推进到故事线。
```

### 生成故事线

```text
世界圣经已确认。请从已确认的世界矛盾生成 3 条故事线。
每条必须标出所用套路、该套路被本世界改写的方式、主角代价、对手的合理诉求、结局承诺和可持续卷数。不要替我选择。
```

### 规划下一卷

```text
以书级创作约定、Canon 和伏笔账本为依据，只规划下一卷。
给出本卷目标、压力最大的世界规则、人物关系变化、节奏板、要兑现和新增的承诺。标出任何需要我确认的重大变更。
```

### 写作并审校一章

```text
先生成第 12 章任务单，等我确认后再写初稿。
初稿完成后，分别以结构、人物、Canon、语言四个维度审校。不要笼统评价；每条问题都要引用具体证据，并给出最小修改方向。
```

## 文件规则

- `世界圣经` 可以包含长解释；`Canon` 只能写原子事实，每条可核查、可引用。
- 章节写完并被作者接受，才更新 `Canon` 和 `章节状态`。
- `伏笔账本` 不是灵感备忘录。每条必须有读者已知程度、计划回收点和当前状态。
- 改动已确认世界规则时，要写一份“变更影响”，列出受影响的章节、角色和伏笔，再由作者确认。

## 如何判断一套设定够不够好

以下问题能快速发现“设定只有名词、没有故事能力”的情况：

1. 规则的代价是否落在具体的人身上？
2. 同一规则是否同时影响制度、关系和日常生活？
3. 主角解决问题时，是否必须牺牲一种重要价值？
4. 反派或对手是否也在合理利用同一套世界规则？
5. 如果删掉这条设定，故事线是否会真正改变？

若前四题多数回答“否”，优先继续建设世界，不要急着写大纲。

## 常见误区

- **让 AI 一次产出所有内容：** 会得到表面完整、内部没有压力的设定百科。应逐层确认。
- **把套路当故事：** “复仇”“升级”“破案”只是结构标签。必须追问：为什么只有这个世界能这样复仇、升级或破案？
- **把每章细纲写死：** 长篇会失去发现感，也让早期错误被放大。只细化临近章节。
- **把评分当决定：** 分数擅长定位异常，不擅长判断审美。作者对“值得保留的怪异”有最终裁量权。
- **一次性全文润色：** 会抹平人物声音。应先结构、再人物、后语言，且保留可回退版本。
